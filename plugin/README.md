# Quote Card Builder — plugin italiano

Questo è il pacchetto plugin di Quote Card Builder per ChatGPT e Codex.

La skill inclusa resta in italiano e guida l’utente dalla scelta della frase alla revisione nel Visual Review Studio, fino alla produzione dei formati social approvati.

Il contenuto di `skills/quote-card-builder/` viene generato dalla skill canonica nella radice del repository. Non modificarlo separatamente: usare `scripts/build_plugin_package.py` per creare un pacchetto sincronizzato.
