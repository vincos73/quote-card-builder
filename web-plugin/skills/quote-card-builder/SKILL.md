# Quote Card Builder — web MCP

Server 1.8.11, editor v1.58. Use the connected MCP tools; this package does not require a local Python runtime. Preserve explicit text, attribution, palette and reuse choices. The model designs; the editor lets the user choose and refine; Download PNG produces the current card.

When a user supplies a quote and asks to proceed, open one populated editor. With a URL, read the source through the host, select a strong exact quote and retain its source status; the server does not fetch URLs. A name must be supplied by the user or established by the source; otherwise leave attribution empty. An omitted palette uses the neutral palette as an initial choice, without claiming it is the user's brand. Do not infer a brand from the source or user identity. If the user opens the plugin without content, call `quote_card_builder_open_workspace` with `{}`.

For a request for Nastri or geometric ribbon compositions, or when no style is chosen in this web pilot, read [the ribbon data reference](references/ribbons-web-mcp.md), then design three native scenes with the same text and selected palette. Pass `visual_grammar: ribbons`, `composition_candidates`, the initially recommended `composition` and `proposal_source: model` to `quote_card_builder_open_editor`. Explain each artistic direction briefly. The three scenes must differ in spatial structure, paths and intersections, with usable text and attribution space; recoloring or shifting the same design does not make a different composition. Make the design appropriate for the quote's length and meaning. Do not rewrite a quote to fit. Preserve an explicit choice of a legacy style.

Use the full expressive range of cubic curves, varying ribbon widths, hierarchy and negative space. Palette colors are roles: choose how to assign the supplied roles, preserving their exact values. Reserve an author zone even when attribution is absent. Default font sizes to automatic unless the user requests exact sizes. Apply sparse meaningful bold or highlight ranges when useful, preserving Unicode offsets and the user's text. The editor also allows independent quote and author size, and a local size multiplier on selected words.

The editor can show deterministic trial scenes when no model scenes were supplied. They are labeled as trials; do not claim they were designed by the model. A genuinely new creative proposal in the same style comes from the model using the saved base, keeping palette and the ribbon vocabulary while designing new paths and text placement. A base imported or shared by the user can seed that proposal. An editor button alone does not invoke a model.

For a follow-up edit, use `quote_card_builder_update_editor`, carrying the current complete snapshot and revision from model context and only the requested changes. Do not reopen the editor or reset its other choices. Changes to text clear obsolete style ranges; unchanged text preserves manual formatting. A text-only chat edit preserves the other fields unless the user also requests a change. When reusing a base for a new quote, the editor resets the previous quote’s ranges and evidence status. The optional author field may be prefilled from the open card; that field determines the attribution, and leaving it empty removes the author. Do not claim the editor always clears the author automatically. Read the reference for the reuse modes and fields.

Visual warnings such as contrast, overflow and overlaps are descriptive, non-blocking notices without correction buttons or instructions. Preserve manual choices. Invalid data, missing resources and failures that prevent creating a PNG remain technical errors. Do not treat a quality assessment as export permission.

The user chooses 4:5, 1:1 or 9:16 in the editor; each selected format is rendered from the same geometry data. Saved bases and drafts belong to the client/device; do not promise cloud synchronization. A saved web base contains the card snapshot, including design, palette, quote, attribution, formatting and alt text. The project JSON also contains the full card and is the explicit transfer mechanism. The local Visual Review Studio uses a different style-base format that excludes editorial content; do not describe that exclusion as a property of web bases.

For remote delivery, show the returned HTTPS PNG as an image and provide its download link. A generated SVG or an image visible only in model context does not prove that a user received a PNG. Do not replace the current card with an image-generation result. Use the headless fallback only after the host reports an actual UI failure, with preview approval and its current SHA-256 as required by the tool.
